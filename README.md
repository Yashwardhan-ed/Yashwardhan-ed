## 💼 Featured Projects

### 🔹 Distributed TypeAhead Search Engine
`Node.js` `Express` `Redis` `PostgreSQL` `Docker`

A low-latency autocomplete engine capable of serving suggestions from millions of search queries.

- Multi-level caching with an in-memory LRU cache + Redis, cutting database lookups and response latency
- Prefix-based search using Redis Strings, with search metadata persisted in PostgreSQL for durability and analytics
- Consistent hashing across multiple Redis instances for horizontal scalability and fault isolation
- Fully containerized with Docker & Docker Compose for easy local multi-node testing

### 🔹 Natural Disaster Tweets Classification (Kaggle)
`PyTorch` `LSTM` `Transformer` `GloVe`

Deep learning models for binary classification of disaster-related tweets, built for the Kaggle Natural Disaster Tweets competition.

- Custom NLP preprocessing pipeline: tokenization, frequency-thresholded vocabulary generation, and sequence padding
- LSTM classifier with pre-trained GloVe Twitter 50-d embeddings, achieving an **F1-score of 77.26**
- Transformer encoder model with GloVe Twitter 200-d embeddings, benchmarked against the recurrent architecture
- Comparative analysis across architectures, embedding dimensions, and training strategies
